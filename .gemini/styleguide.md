# Key Principles
* **Readability:** Code should be easy to understand for all team members.
* **Maintainability:** Code should be easy to modify and extend.
* **Consistency:** Adhering to a consistent style across all projects improves
  collaboration and reduces errors.
* **Performance:** While readability is paramount, code should be efficient.

## Language
* **Source Code Language:** All comments in source code must be written in English.
* **Conversation Language:** Pull request messages, reply messages and other conversations (except for source code comments) in GitHub must be written in both English and Japanese.
